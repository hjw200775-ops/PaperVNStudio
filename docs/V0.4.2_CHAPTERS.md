# V0.4.2 · 章节与段落管理

范围：把长剧情整理成「章节 → 段落 → 句子」，快速定位、移动、从指定位置试玩。不做音频、TTS、Live2D、好感度、条件系统、EXE 导出与云服务。

## 1. 数据结构（schema 5）

```json
{
  "chapters": [
    { "id": "ch_…", "title": "第一章", "collapsed": false,
      "paragraphs": [ { "id": "pg_…", "title": "早餐", "collapsed": false } ] }
  ],
  "nodes": [ { "id": "home_01", "…": "…", "paragraphId": "pg_…" } ]
}
```

- 章节与段落都是**稳定 ID**；句子只记录 `paragraphId`，章节归属由段落推出，因此改名不影响任何引用。
- **`nodes` 数组仍是播放顺序的唯一依据**。树只是按 `chapters → paragraphs → nodes` 把同一份数组归并显示，不维护第二份节点顺序。
- 显式 `next`、选项 `target`、结局都继续用节点 ID 引用，本版不重写它们。
- 段落与章节的先后就是显示顺序，也是「按顺序继续」的顺序；两者被有意绑定在一起，任何会改变它的操作都会先列出受影响的句子。

## 2. 迁移（schema 4 → 5）

旧工程没有章节信息，迁移时建立「第一章 / 默认段落」并把所有句子放进去：节点 ID、文本、说话人、角色、图层、演出、分支全部原样保留，不自动覆盖旧文件。空章节/空段落可以正常保存与重开。

## 3. 左侧章节树

- 折叠/展开（状态随工程保存），标题与句数；长标题省略并在悬停时显示完整内容。
- 拖动句子到另一个段落、拖动段落到另一个章节、拖动章节调整先后；都有落点高亮。
- 替代操作：「移动到…」对话框（句子选段落、段落选章节，下拉里显示「章 / 段」）、句子的「↑ / ↓」在段内上下移动、章节的「↑ / ↓」调整先后。
- 删除章节或段落默认**保留剧情**，句子进入「未分组」，播放顺序不变；删除单句会先说明有多少跳转指向它。所有改动都可撤销。
- 拖动或移动导致「按顺序继续」的去向改变时，先弹窗列出「原来到哪句、移动后到哪句」，确认后才执行；显式跳转与选项不受影响。

## 4. TXT 导入预览

支持的格式（其余行按旁白处理）：

```
# 第一章
## 早餐
林悠：豆浆快凉了。
林澈：来了。
两人低头吃饭。
```

- 预览显示：识别到的章/段/句数量、绑定到角色的句数、保留自由文本的句数、旁白句数、将新建的结构、无法识别的行（带行号与原因）。
- 导入目标二选一：按文本里的标题新建章节/段落，或全部进当前段落。
- 角色只在**名字唯一匹配**时绑定；重名或未登记时保留自由文本说话人并提示；不自动创建角色、不推断选项或结局。
- 取消不改工程；确认后一次写入，可整体撤销。

## 5. 剧情检查与定位

`analyze()` 现在返回结构化的 `issues`（`level` + 文本 + `nodeId`），`errors` / `warnings` 保留为字符串数组以兼容旧调用。检查弹窗按错误/提示分级列出，点击带「定位 →」的条目会展开对应章节与段落、选中该句并把焦点放到编辑区。循环、未使用素材等仍只算提示，不阻止导出。

## 6. 从指定位置试玩

「▶ 从本句」「▶ 从本段」复用同一套 `scene` / `castAlong` / `effects` 解析，不另写播放器。路径判定由 `C.entryPlan()` 负责：

1. **正在试玩且就在这一句**：直接沿用真实走过的 `trail`。
2. **目标本身是独立场景**：从该场景开始，不回溯任何前置。
3. 否则反向找所有能到达目标句的进入点（独立场景 + 第一句），正向枚举路径；每条路径**归一化到「最后一个独立场景 + 它之后的尾巴」**——因为独立场景会同时重置图层、角色表情与持续效果，之前的路径不再影响本句状态。
4. 尾巴唯一 → 直接还原；尾巴有多种 → 弹出「这句前面有多条路线」，列出每条路线经过的句子，作者选一条后按该路线还原。**不会把多条分支拼在一起**，也不会拿「数组顺序扫过所有前置节点」的结果冒充本句状态。
5. 完全找不到入口时只提示从更靠前的场景入口试玩，不编造状态。

显式 `next`、选项、结局仍按节点 ID 解析；`hold` 持续效果遇到独立场景重置，`sentence` / `auto` 规则不变。

## 7. 验证

```bash
node scripts/check.cjs                     # 含 tests/chapters.test.cjs
npm run desktop:smoke                      # 真实窗口（含导入预览流程）
npm run chapters:acceptance                # 章节整理、拖动、影响提示、定位、定点试玩、导入预览、保存导出
PAPER_CHAPTERS_REOPEN=1 npm run chapters:acceptance   # 新进程重开
npm run branch:evidence                    # 三条分支的节点路线与结尾截图
```

`tests/chapters.test.cjs` 覆盖：schema 5 迁移、树与计数、移动影响计算、显式 next 不被改写、删除分组保留剧情、从中间试玩不串场景、TXT 解析（重名/无法识别/导入目标）、落盘回读与导出播放一致性。
