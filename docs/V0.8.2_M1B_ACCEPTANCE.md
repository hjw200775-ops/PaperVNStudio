## 1. 实现要点

| 需求 | 落地 |
|---|---|
| M1B-1 拉伸 | 左右边缘手柄：右边缘保持 start 只改 duration；左边缘保持 end 改 start+duration；实时显示起点/终点/时长；零时长 `◆` 事件无手柄；Esc/无位移/取消不写数据；一次有效拖动一次撤销 |
| M1B-2 缩放滚动 | `pps` 1–4000 px/s；放大/缩小/适应范围/默认、Ctrl+滚轮；锚点（鼠标或播放头）时间点稳定；轨道名列 `sticky` 固定、片段区独立横向滚动；刻度/网格/片段同处一个 content 坐标系；`relayout()` 只改样式不重建片段 DOM；0s 刻度完整可读 |
| M1B-3 吸附 | 关闭 / 0.1 / 0.25 / 0.5 / 1 秒；参考网格、所有片段 start/end、播放头、0；阈值 `8px / pps`（随缩放自适应）；橙红参考线；Alt 临时关闭；移动与拉伸同一规则；统一 1ms 精度防漂移 |
| M1B-4 多选批量 | Ctrl 点击、Shift 范围、点空白取消；共同移动保持相对间隔；负时间钳制；一次撤销；未选动作不写 `start`；切节点清空；Esc 取消 |
| M1B-5 复制粘贴删除 | Ctrl+C / Ctrl+V（以播放头为起点）/ Ctrl+D / Delete；新唯一 ID、保留类型参数素材引用与动作间隔、不复制素材文件；删除多个一次编辑；Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z 沿用全局；仅在时间轴焦点生效，输入框不拦截 |
| M1B-6 轨道组织 | 固定轨道顺序 + 按 `char:<id>` 拆角色子轨道并显示角色名；折叠/展开、空轨道开关；折叠只改显示，不改工程数据与发布行为 |
| M1B-7 稳定性 | pointerdown 不重建交互目标；pointercancel / lostpointercapture / Esc / 切节点 / 缩放 / 滚动取消拖动；删除选中片段、撤销重做后按 ID 恢复选择；document 级监听器只注册 1 次；pointermove 只改临时 DOM，不写工程、不建快照 |

**相对→绝对规则（明确且可预测）**：被拖动 / 批量移动 / 左边缘拉伸 / 粘贴的动作写 `start`（转成绝对时间）；
未选中的相对动作保持 `after/parallel + delay`，由现有 `schedule()` 自然跟随。绝不把整个节点批量转成绝对时间。

### C. 尚未测试 / 本轮明确不做

- 音频波形、轨道独奏/静音混音、高级关键帧、视频轨道、Live2D 轨道 —— 本轮不做。
- 跨节点 / 跨章节时间轴、连续音视频播放调度 —— 本轮不做（M2 起评估）。
- 1.47 GiB 工程全链验收、900 秒音频浸泡 —— 本轮未改音频引擎 / 资源存储 / 核心调度，按范围不重复执行。
- 人工长时间使用体验、第二台机器验收、最终艺术方案 —— 由用户决定。
