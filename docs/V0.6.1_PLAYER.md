# V0.6.1 标题页与游戏菜单

基线：`f3c0664`（V0.5 收尾）。本轮只改播放器、导出骨架、编辑器「完整预览」接线与相关测试，不新增依赖、不改工程 schema、不推送远程。

## 一、播放器状态

`dist/player.js` 由「加载即开画」改为状态机：

| 状态 | 可见内容 | 说明 |
| --- | --- | --- |
| `title` | 标题页 | 标题、开始、继续、设置；不绘制剧情、不播放任何声音 |
| `playing` | 舞台 + 播放条（上一步 / 重新开始 / 菜单） | 点击舞台或空格 / Enter 推进 |
| `menu` | 菜单遮罩 | 返回游戏、保存、读取、设置、返回标题 |
| `settings` | 设置遮罩 | 总 / 音乐 / 音效 / 语音音量、静音、启用声音；从标题或菜单进入，Esc 回上一级 |
| `confirm` | 重新开始确认 | 有进度时先确认，不删除存档 |

- 只有 `playing` 会推进台词；菜单、设置、确认遮罩打开时舞台点击被遮罩拦截，`next()` 也检查状态。
- Esc 单键只做一个动作（设置 → 菜单 → 游戏 → 菜单），忽略 `e.repeat`；输入框 / 下拉 / 文本域内的空格与 Enter 不被全局快捷键抢走。
- 打开菜单聚焦「返回游戏」，关闭后回到「菜单」按钮；设置关闭回到进入它的按钮；Tab 与 Enter 使用浏览器原生行为。
- 结局节点仍显示播放条，可打开菜单并返回标题。

## 二、音频

复用 V0.5 的 `dist/audio.js`，没有第二套偏好或音量算法。

- 标题页只创建运行层（用于设置里的解锁与音量展示），**不调用 `enter`**，所以没有 BGM / 语音 / 音效 / 延迟任务。
- 「开始游戏」「继续游戏」在点击处理链里 `audio.unlock()`；失败也进入游戏，并提示「可以无声游玩，稍后在设置里重试」，不假报解锁成功。
- 设置里的 `setPrefs` 只改音量与静音，不重启当前 BGM。
- 菜单开关不重绘、不重新 `enter`，不会重复触发语音、音效或演出。
- 返回标题：`cancelEffect()` 取消视觉演出，`audio.stopAll()` 停止 BGM / 语音 / 音效、取消延迟任务与淡变回调并递增 generation；等待后旧任务不会复活。
- 设置里的「启用声音」重试只恢复当前句 BGM（`stopAll` 后按 `bgmAt` 重建），不重置剧情、不叠音；无音频工程隐藏音频区并显示「本作品没有音频」。

## 三、存档与继续

沿用 `paper-game-<projectId>` 单槽与 `{id, trail}` 格式，不迁移。

- 只有点「保存进度」才写入；开始新游戏、返回标题都不覆盖存档。
- 读取时校验：JSON 可解析、节点仍在、trail 中每个节点存在、trail 从故事首节点开始、trail 相邻节点在 `C.edges` 中可达、trail 最后一项能到达目标节点；空 trail 只允许停在首节点。
- 任一校验失败：标题页「继续游戏」禁用并给出中文原因（损坏 / 节点已删除 / 路径失效 / 分支不一致），**不删除原存档**，不跳到别的句子；游戏内「读取进度」也显示同一原因。
- `localStorage` 读写抛错：保存显示「未能保存：浏览器不允许写入存档或空间不足；游戏仍可继续」，游戏状态不变。
- 保存成功后更新 `saveInfo`，返回标题时「继续游戏」立即可用。

## 四、编辑器与导出

- 导出 HTML 骨架改为：标题页 → 舞台 + 播放条 → 菜单遮罩 → 设置遮罩 → 重新开始确认。原有 `#scene`、`#layers`、`#text`、`#save`、`#load` 等 ID 保留，便于回归测试复用。
- 编辑器「完整预览」按钮：生成与导出**同一份** `buildGameHTML` 结果；桌面端通过 `player:preview` 写到 `userData/preview/game-preview.html` 并在独立 `BrowserWindow`（sandbox / contextIsolation）打开；Web 端用 Blob URL 新窗口。
- 「从本句 / 从本段试玩」仍是编辑器自己的舞台，不经过标题页；「退出试玩」只退出编辑器试玩，播放器里的「返回标题」不会关闭编辑器。
- 玩家菜单只有游戏内能力，不含打开工程、保存工程、导出等编辑器操作。

## 六、已知边界与未验证项

1. 单槽手动存档；没有自动存档、多槽、存档命名或跨设备同步。
2. 「开始游戏」不删除旧存档；有进度时重新开始使用播放条上的「重新开始」并二次确认，菜单里没有额外的「重新开始」项。
3. 菜单打开时不做音频/演出的时间暂停，当前 BGM、语音、音效与视觉演出继续；没有独立的暂停/恢复引擎。
4. 标题页没有标题音乐、主题编辑或背景图配置。
5. 存档只保存 `{id, trail}`，不保存播放秒数；继续 / 读档的 BGM 从曲首重建。
6. **未验证**：真人点击与人工听审（自动化只注入输入事件，不评价听感）；第二台电脑与安装包；编辑器「完整预览」窗口的真人操作未单独验收。

## 七、人工检查步骤

1. 打开 `F:/Wanfeng-Demo/验收结果-v061/wanfeng-player.html`（或编辑器「完整预览」）。
2. 标题页确认继续按钮为禁用、下方说明没有存档；点「开始游戏」听到 BGM。
3. 点「菜单」或按 Esc；点舞台确认台词不动；Esc 返回游戏。
4. 菜单 →「设置」→ 拖动音乐滑块，确认音量变化且音乐没有从头开始；Esc 回菜单。
5. 「保存进度」→「返回标题」→ 确认「继续游戏」可用 → 进入后回到保存的句子。
6. 返回标题，等待 2 秒，确认没有旧音乐 / 语音 / 音效重新响起。
7. 进结局后打开菜单，确认可以「返回标题」。
