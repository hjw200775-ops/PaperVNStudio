# V0.8.2 · M2-A 音频波形与时间轴预览基础 · 验收记录

> 基线 `941dc00`（M1-B），分支 `feature/v0.8.2-timeline`；开工时 Git 干净、`main` 未动、未推送。
> **冻结模块全部未改**：`dist/audio.js` 核心音频引擎、`dist/player.js`、`dist/performance.js` 核心调度与求值、
> `dist/core.js` 迁移语义、V0.7.6 资源存储架构。波形复用 `runtime().decodeWaveform` 的既有解码与 64 MiB 缓存，
> 预览只调 `stateAt()/applyDOM()`，未重写音频引擎。未出现必须修改冻结模块的证据。

## 1. 实现要点

| 需求 | 落地 |
|---|---|
| M2A-1 波形数据层 | 新增 `dist/timeline-waveform.js`：真实峰值摘要（min/max、时长、采样率、声道、SHA-256 内容标识）；懒加载、串行请求（避免 `decodeWaveform` 的 `loadSeq` 互判 stale）、重复素材复用、加载中/失败标记、过期结果丢弃、切节点 scope 管理、条目数与 2 MiB 字节上限、长素材降 bins、超预算素材拒绝；只缓存摘要不存 PCM |
| M2A-2 波形显示 | BGM/SFX/Voice 片段内 Canvas 绘制；**时间轴 1 秒 = 素材 1 秒**，BGM 淡入动作只显示素材开头对应秒数，不压缩整曲、不暗示裁剪/变速；超出素材时长画斜纹并标「持续/循环」；淡入淡出用半透明遮罩区分；零时长瞬时事件保留 `◆` 标记并用提示展示素材真实时长；随缩放/滚动/移动/拉伸/折叠/素材替换/删除/撤销更新，`relayout()` 只改样式不重建片段 DOM |
| M2A-3 播放控制器 | 新增 `dist/timeline-preview.js`：`idle/playing/paused/stopped/ended`；**单调时钟** `anchorT + (now()-anchorWall)/1000`，不累加固定帧增量；播放/暂停/继续/停止/重播/任意起点/自动结束；单个 rAF 幂等；`previewStart/Pause/Resume/Seek/Stop/Loop/End` 事件钩子（M2B 接口准备，不执行音频）；帧率/最差帧统计；不写工程、不建撤销 |
| M2A-4 连续视觉预览 | 每帧按当前绝对时间 `PF.stateAt()` 从进入前状态重算 + `PF.applyDOM()`；角色/背景/镜头/特效/并行均由既有求值器驱动；连续播放终态与直接定位同一时间一致、反复播放无漂移 |
| M2A-5 区间循环 | 预览区间与循环开关是编辑器临时视图状态，不写工程、不混入 BGM 素材循环配置；区间高亮、播放头在区间内重复；循环回起点重新求舞台状态，无累积与历史音频副作用 |
| M2A-6 界面 | 工具栏播放/暂停/停止/重播/起点、区间循环、自动跟随、区间起止与设置/清除、当前时间/总时长/状态；Space 播放暂停、Esc 停止、Home 回起点，遵守焦点规则（输入框不拦截）；播放头接近边缘自动横向滚动，用户滚动/缩放后短暂抑制跟随；每帧只更新播放头与舞台，不重建片段 DOM |
| M2A-7 编辑关系 | 播放/暂停中的编辑、撤销重做、删除、切节点 → `preview.invalidate()` 停止旧计划并递增代际；`dispose()` 释放 rAF、波形缓存与全部全局监听器；无多个并行控制器；不影响正常游戏试玩 |
| M2B 接口准备 | 7 个预览事件只 emit 并记录，不触发正式音频演出；界面明确标注「**当前为视觉连续预览，完整音频同步将在 M2B 接入**」，避免把静音误判为故障 |

**明确区分**：A 时间轴演出循环预览（本轮实现，视觉）；B BGM 素材自身精确音乐循环（V0.8.1 既有，未改动）。

## 3. 性能与资源（真实窗口采样）

| 指标 | 实测 |
|---|---|
| 波形生成 | 单次解码耗时 ≈50.9ms；摘要缓存 2 条 / **2328 B**（上限 2 MiB）；`cacheHits=32`、`decodeCalls=3`、`failures=0`、`staleDiscarded=1` |
| 波形像素 | canvas 非零像素 **25056（ratio 0.997）**；摘要时长 41.4s = 工程素材时长 41.4s |
| 100 动作节点 | 100 个片段 DOM、渲染 ≈18.6ms、全局监听器 7 个（不重复注册） |
| 连续启停 100 次 | `maxRaf=0`、状态 stopped、DOM 稳定 1498 |
| **连续播放 5 分钟以上** | 真实单调时钟 **300193ms**、**161 次区间循环**、20 个采样点；**30020 帧**、最差帧 **12.2ms**、平均 10ms、**最低 fps 100**；`activeRaf ≤ 1`、停止后 0 |
| 资源稳定性 | 长播放 `domDelta=0`；JS 堆 11.49 MB → 11.63 MB（+0.14 MB）；无渲染进程异常 |

时间轴长度覆盖 0.5s / 10s / 60s / 300s+ 与 100 动作；多次切节点后过期波形请求被丢弃。
逐段采样明细见 `evidence.longPlay` / `evidence.performance`。
