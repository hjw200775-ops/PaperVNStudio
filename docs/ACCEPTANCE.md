# 实机迁移验收清单

用一个小工程覆盖全流程：两个角色、两个背景、十几句对话、三个局部分支再汇合、一个结局、一次角色特写与背景虚化。使用自己拥有使用权的素材。

## A. 网页基线（先执行）

- [ ] `node scripts/check.cjs` 通过。
- [ ] 本地页面能打开，导入 TXT，正确区分角色与旁白。
- [ ] 背景和角色可拖动、缩放，图层排序/锁定/隐藏正常。
- [ ] 三选项进入不同对话后汇合；显式跳转在剧情重排后不变。
- [ ] 缩放和背景模糊正常；终态、时间预览、返回布局不改变原始尺寸。
- [ ] 三种恢复策略分别按约定生效；效果修改可撤销/重做。
- [ ] 导出 HTML，断网后仍可运行，图片不丢失，分支与效果正常。

## B. 桌面窗口

- [ ] 无开发服务器也能启动打包后的独立窗口。
- [ ] 普通编辑快捷键与文本输入不冲突。
- [ ] 渲染进程无法任意访问文件或执行 shell；导航行为受控。

## C. 工程与素材

- [ ] 新建/打开/保存/另存为均可用。
- [ ] 导入旧 `.paper.json` 后，剧情、图层、分支、效果与预设保留。
- [ ] 保存退出再打开，数据完整。
- [ ] 工程放在中文、空格路径下正常。
- [ ] 移动整个工程目录后仍能打开，不依赖旧位置。
- [ ] 删除最初用于导入的外部图片副本后，工程仍正常。
- [ ] 两张不同但同名图片不会互相覆盖。
- [ ] 另存为后旧工程保持不变，新工程不引用旧素材目录。
- [ ] 文件占用/无权限/保存失败时，旧工程仍可恢复。
- [ ] 异常关闭后能找到有效备份，备份引用的图片可用。
- [ ] 未保存关闭时提供保存/放弃/取消，失败不自动退出。

## D. 导出与另一台电脑

- [ ] 导出文件不含本机资源绝对路径、失效 blob URL、开发服务器依赖。
- [ ] 副机无需制作器和 Node 即可用浏览器打开 HTML 游戏。
- [ ] 分支汇合、持续效果、句间恢复、读档终态一致。
- [ ] Windows 制作器打包命令、产物位置与运行限制已记录。
- [ ] 未能执行的项目单独列明，不标成通过。
