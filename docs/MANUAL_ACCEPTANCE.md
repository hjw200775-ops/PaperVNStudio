# 人工验收操作单（C 层 / D 层）

这份单子只放**必须由人做**的检查。自动化与真实窗口烟测已覆盖的部分不在这里重复。

- 全程约 25 分钟（C 层 15 分钟 + D 层 10 分钟）。
- 规则：没做的项留空，不要勾。**未执行 ≠ 通过**。
- 出问题时记下「现象 + 第几步 + 截图」，比记「失败了」有用得多。

## 0. 准备

1. 在 [Releases](https://github.com/hjw200775-ops/PaperVNStudio/releases/tag/v0.3.1) 下载两个文件。
2. 校验哈希（应完全一致）：

```powershell
Get-FileHash .\PaperVNStudio-0.3.1-win-x64-portable.exe -Algorithm SHA256
Get-FileHash .\PaperVNStudio-0.3.1-win-x64-setup.exe   -Algorithm SHA256
```

| 文件 | 期望 SHA-256 |
| --- | --- |
| portable | `8b0fe9fe194ba0c1f125f143d4d15e4e7ca5cf7ee30c8cf27c19a6470fa8593e` |
| setup | `56c8cb40e28afe45012d86434200c4de4ee940af5ae24f9039e74a6dadf2dca5` |

3. 新建一个空目录当工程目录，例如 `D:\pvn-acceptance\story`。**必须是空目录**，已有工程会被拒绝。
4. 准备两张图：一张横图（背景用）、一张竖图（角色用）；再复制其中一张并改名，用来测「同名不同图」。

## C 层：本机人工点击

### C1 原生对话框（约 4 分钟）

启动 `portable.exe`（SmartScreen 提示选「更多信息 → 仍要运行」）。

- [ ] 点「新建工程」，弹出系统目录选择框；选中第 3 步的空目录
      → 状态栏显示工程名与路径，编辑器里有一个可编辑的对话节点
- [ ] 点「打开工程」，选中刚创建的 `story` 目录
      → 工程重新载入，节点与标题与保存前一致
- [ ] 点「另存为」，选另一个空目录 `story-copy`
      → 新目录生成 `project.paper.json`、`assets/images/`、`backups/`
- [ ] 菜单「文件 → 最近工程」里能看到 `story`
      → 点击后能打开
- [ ] 在对话框里点「取消」
      → 不报错、不改当前工程

### C2 未保存关闭的三选一（约 2 分钟）

- [ ] 改一句台词（不要保存），点窗口右上角关闭
      → 弹出保存 / 放弃 / 取消
- [ ] 选「取消」→ 窗口留着，改动还在
- [ ] 再次关闭，选「放弃」→ 窗口关闭；重新打开 `story`，那句改动不在
- [ ] 改一句 → 关闭 → 选「保存」→ 窗口关闭；重新打开，改动在

### C3 画布手势（约 4 分钟）

- [ ] 导入一张背景、一张角色立绘，画面上出现两个图层
- [ ] 用鼠标拖动角色到左下角 → 图片跟随，松手不回弹
- [ ] 拖右下角缩放手柄 → 按比例变化；勾选「锁定比例」后再拖，比例不变
- [ ] 图层列表里「上移 / 下移」→ 叠放顺序变化，画面同步
- [ ] 点「锁定」后尝试拖动 → 拖不动，输入框变灰
- [ ] 点「隐藏」→ 画面消失，再点恢复
- [ ] 切到「演出」面板加一个缩放效果，点「试玩」
      → 角色按效果动起来，台词切换时效果按策略结束

### C4 素材语义（约 3 分钟，重点）

- [ ] 同一张横图，先「上传背景」，再「上传角色」
      → 图层列表出现两条，标签分别是「背景」和「角色」；角色那条是竖着按比例的、站在下方，**不是**铺满画面
- [ ] 再把同一张图当背景导入一次
      → 只有图层变多，素材没有被提示重复、自动保存没有报错
- [ ] 导入两张同名但内容不同的图（同名不同图）
      → 两条图层都在，切换选择时画面不同，互不覆盖
- [ ] 给复用同一张图的两个图层分别改大小、位置，各加一个不同效果
      → 互不影响
- [ ] 关闭再打开工程 → 以上位置、大小、效果都还在

### C5 安装向导（约 2 分钟）

- [ ] 运行 `setup.exe`，能进入安装向导、可改安装目录
- [ ] 安装完成后开始菜单/桌面有快捷方式，能启动
- [ ] 从「应用和功能」卸载，安装目录被清理，快捷方式消失

### C6 导出 HTML 双击试玩（约 1 分钟）

- [ ] 「导出试玩」保存为 `game.html`，双击用浏览器打开
      → 图片、分支、效果都正常，控制台无报错
- [ ] 断网（关 Wi-Fi / 拔网线）后再打开一次 `game.html`
      → 仍然正常，说明没有外部依赖

## D 层：另一台电脑（约 10 分钟）

用一台**没装 Node.js、没装本项目**的 Windows 机器。把 `portable.exe` 和 `game.html` 拷过去（U 盘或聊天工具均可）。

- [ ] 断网状态下双击 `portable.exe`
      → 能启动，显示示例工程；新建工程、导入图片、保存、重新打开都正常
- [ ] 同机双击 `game.html`
      → 浏览器能玩，图片不缺失
- [ ] 把工程目录从 `U盘` 拷到桌面后重新打开
      → 移动目录后仍可打开，素材不丢（内容寻址素材路径是相对的）

> 若失败，优先记录：系统版本、是否 64 位、失败时屏幕提示原文。
