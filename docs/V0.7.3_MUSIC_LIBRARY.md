## 三、素材库怎么用

- **导入**：素材库读 `manifest.json`，把 `category / mood_tags / scene / 时长 / 响度 / sha256` 一起入库；不转码、不重采样（保持 OGG 原文件）。
- **检索**：分类下拉（背景音乐 / 音效 / 语音）+ 情绪标签下拉（标签从素材里自动收集）。未引用的曲目直接标「未引用」。
- **试听**：行内「试听 / 停止试听」，不离开编辑器。
- **绑定**：BGM 行有「绑定到场景」。它只给**每个段落的第一句**写 `play`，其余句子自然沿用；批量编辑勾选多句时按段落去重，一次改多个场景。「清除所选音乐」把入口的指令移除（`bgm: null`），后面的句子回到纯继承。
- **撤销**：绑定与清除各算一次撤销记录，`Ctrl+Z` 一次退回整批。

## 四、标题音乐

`p.titleMusic = { audioId, volume, fadeIn, loop }`，是可选增量字段：没配置就完全不出现在工程里（旧工程、磁盘往返、备份都不受影响）。

实现上它走**独立的 `<audio>` 通道**，不占 `audio.js` 的剧情 BGM 槽位，所以：

- 标题页循环播放，进入游戏（开始 / 继续）立刻 `pause`，不与场景 BGM 叠加；
- 从游戏返回标题时 `play()` 续播，**currentTime 不归零**（实测 0.86 s → 2.09 s）；
- 页面 `pagehide` / `beforeunload` 时停止、清 `src`、移除元素，释放解码器与文件句柄。

## 五、导出只带被引用的曲目

`buildGameHTML` 在打包前用 `referencedAudioIds()` 收一遍引用面（剧情 bgm/sfx/voice + 标题音乐），只把命中的音源内嵌进 HTML，其余留在工程素材库里。`.manifest.json` 新增 `audio` 字段：

```json
"audio": { "library": 6, "included": [ … 3 首 … ], "excluded": [ … 3 首 … ] }
```

当前《晚风》实测：包内 3 首（主题曲 + 早晨 + 上学路），排除另外 3 首。

## 六、替换完整版

素材 id 固定为 `audio_<曲目ID>`，`meta.trackId` 是逻辑曲目号。`scripts/import-ost.cjs` 重跑时按 `trackId` 命中已有素材，**只替换音源文件与时长，id 不变**，所以剧情绑定与标题音乐引用全部保留：

```bash
node scripts/import-ost.cjs \
  --package "F:/Wanfeng-Demo/素材交付/Wanfeng_OST_Vol1_Release" \
  --project dist/samples/wanfeng-ch01/project.paper.json \
  --title-music ost_01_title \
  --bind "早餐=ost_02_morning" --bind "上学路=ost_03_school_road"
```

磁盘仍是内容寻址（`assets/audio/<sha256>.ogg`），换完整版会落新文件、旧文件不再被引用，备份与恢复逻辑不变。
