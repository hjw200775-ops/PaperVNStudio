# 纸间 Story Studio · V0.3

无构建依赖的中文 Galgame 网页编辑器，入口为 `dist/index.html`。

## 创作

- TXT / 键盘录入、旁白、任意选项、局部分支与汇合。
- 图片图层拖动、等比缩放、锁定、隐藏、排序、透明度、场景预设。
- 新节点沿用上一个画面，编辑继承图层时创建副本。
- 逐句添加缩放、移动、淡入淡出、模糊、亮度、对比度、饱和度与旋转。
- 提供角色特写＋背景虚化、淡入、淡出、回忆色调、恢复默认效果预设。
- 效果具有起点、终点、延迟、时长、缓动、缩放/旋转中心、恢复规则。
- 工程自动保存在浏览器；下载 JSON 包含原图、图层、剧情与效果。可打开 V0.1、V0.2 工程。
- 独立 HTML 游戏使用与编辑器相同的效果计算和渲染器，不需要联网或制作器。

## 演出约定

- 布局模式显示原始图层，便于拖动；效果终态、预览本句或时间条用于查看演出。
- `hold`：推进时将目标值延续到后续继承场景（即使提前推进）。
- `sentence`：当前节点展示效果，离开后回到此前持续状态。
- `auto`：到目标值后，在指定时长内回到起点；离开后不延续。
- 独立场景重置此前持续效果；继承场景在试玩时依据实际分支路径继承。
- 同一节点同一图层同一效果仅有一条曲线；重复使用同类型预设更新该效果。
- 读档和后退恢复本句终态；重新进入正常剧情会播放本句效果。
- 位置移动使用舞台百分比，缩放使用相对布局尺寸的百分比，模糊按 1280px 基准画布缩放。
- PNG 合成只导出原始布局，不烘焙逐句效果。效果随 HTML 游戏导出。
- 这是轻量演出面板，尚无完整多关键帧时间轴、音频或 EXE 打包。

```sh
node --check dist/app.js
node --check dist/player.js
node --check dist/effects.js
```
