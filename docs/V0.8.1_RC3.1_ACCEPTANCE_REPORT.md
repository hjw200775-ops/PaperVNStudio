## 1. M1 · Voice 播放失败根因（已定位、已修复、已复验）

### 1.1 根因

上一轮 15 分钟浸泡从第 40 秒起持续出现「播放失败（段落 6 · 第 41 句）」。定位过程：

| 检查项 | 结论 |
|---|---|
| 音频文件存在且内容完整 | ✅ `track_018` = 60s / 10.5MB / 44.1kHz 16-bit 立体声 PCM WAV，文件头合法 |
| WAV 能否正常解码 | ✅ 实机起播延迟 **186ms**（不是「文件太大起播太慢」） |
| 素材引用与资源 URL | ✅ 内容寻址 `paper://app/asset/…` 正常 |
| play() 实际结果 | ❌ **AbortError**（"The play() request was interrupted by a call to pause()"） |

**根因**：浸泡每 ~900ms 推进一句；60s 配音的 `play()` 尚未完成就被切句打断，浏览器以
`AbortError` 拒绝。旧 `classifyError()` 不认识 AbortError（只认 NotAllowed / NotSupported），
于是落到 `unknown`，记成「播放失败」并**永久挂横幅**。这既是「错误横幅假阳性」，也掩盖了
「合法打断」与「真正失败」的区别。

### 1.2 修复

`dist/audio.js` 的 `start()` 现在把「通道已停止（`ch.done`）/ 代际过期 / AbortError 打断」
判为**合法取消**（事件 `play-cancelled`），不记错误、不计 `failed`、不污染状态栏；
真正失败（NotSupportedError、中途 `onerror` 解码失败）照常记 `play-failed` / `decode-failed`。

### 1.3 回归证据

- 单测 `tests/audio-playback-events.test.cjs`：打断记 `cancelled`、失败记 `failed` + 错误、完成记 `completed`。
- 实机 `scripts/v081rc3-voice-verify.cjs`（真实 Chromium 解码 track_018）：起播 186ms；打断后
  `cancelled=1`、`failed=0`、无错误。
- 900 秒浸泡：`requested=427, started=383, cancelled=44, failed=0, decodeFailed=0`（见 §6）。

## 2. M2 · 验收系统假阳性修复

### 2.1 事件分类

`dist/audio.js` 新增播放事件统计 `playbackStats()`：

`requested / started / completed / cancelled / failed / decodeFailed / fallback`。

`snapshot()` 额外暴露 `errors`、`playbackStats`、`dualBgm`（精确+流式同时存在 = 双 BGM 直接检测）。

### 2.2 严格浸泡断言

`scripts/v081rc2-soak-editor.cjs` 新增：意外播放失败、素材解码失败、错误横幅、
播放事件数量关系失衡（requested ≫ started+cancelled+failed）、双 BGM 叠加，任一命中即 FAIL。

### 2.3 负向验证（硬性要求）

`tests/audio-negative.test.cjs` 人为构造受控失败，确认「失败必然被发现」：

| 场景 | 结果 |
|---|---|
| 缺失素材 | ✅ 记 `missing`，严格断言 FAIL |
| 播放拒绝 NotSupportedError | ✅ 记 `decode`，严格断言 FAIL |
| 播放中途解码失败（onerror） | ✅ `decodeFailed=1` |
| 合法取消（AbortError 打断） | ✅ `failed=0`，不误报 PASS |
| 正常起播 | ✅ 严格断言 PASS |

## 3. M3 · 编辑器内循环试听工具

- 新增 `dist/loop-audition.js`（轻量组件，不做多轨时间轴）：
  - 音频名称、总时长、波形（按需生成，`decodeWaveform` 复用 64MiB 缓存，大文件降采样峰值摘要）；
  - 播放头、可拖动 A/B 标记、整曲/区间/不循环、精确起止时间输入、播放/暂停/停止；
  - **循环边界试听**：从终点前 3s 起播，穿过边界回跳起点后继续 2s，可反复试听；
  - 候选区间、应用/重置/取消；关闭即释放播放实例与临时资源。
- 运行时新增 `loopPreview`：与发布游戏一致的 `AudioBufferSourceNode + loopStart/loopEnd`，
  接同一根 bgm 总线（音量/Ducking/master 语义一致），但不占用 BGM 槽、不影响当前工程播放状态。
- 标题音乐面板加入「循环模式 + 区间输入 + ♪ 循环试听」；对《晚风》标题曲提供 A/B/C/D 候选
  （**仅本曲，非通用默认值**）；交叉淡化 D 为实验能力，编辑器内明确标记为「独立试听页可用」。
- 数据一致性：循环参数写入 `titleMusic.loopStart/loopEnd`，`toTitleMusic` 已保留区间（RC2 修过），
  非法区间（终点 ≤ 起点）在应用与保存处拒绝。
