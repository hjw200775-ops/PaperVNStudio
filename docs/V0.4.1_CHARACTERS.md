# V0.4.1 · 角色与表情管理

范围：只做「角色 / 表情」这一层。章节系统、音乐与 TTS、变量与好感度、完整时间轴、Live2D/AI 动作、远程仓库发布都没有进入本版。

## 1. 数据模型（schema 4）

工程根新增 `characters`：

```json
{
  "id": "ch_…",              // 稳定 ID，改名不变
  "name": "林悠",
  "color": "#3f6753",        // 姓名颜色，空串表示沿用默认
  "defaultExpressionId": "ex_…",
  "expressions": [
    { "id": "ex_…", "name": "自然", "assetId": "you_neutral" }
  ]
}
```

- 表情只存「名字 + 素材 ID」。素材本体仍是 `assets[]`（内容寻址的图片），用途仍是 `kind: 'char' | 'bg'`。
- 节点新增：`speakerId`（谁在说）、`expressionId`（说话人本句用哪个表情）、`cast`（同场其他角色的表情，`[{characterId, expressionId}]`）。
- 图层新增：`characterId`（这张图属于哪个角色）、`expressionId`（作者录入时的表情）。
- 四个层次互不复用 ID：角色身份 ≠ 表情身份 ≠ 素材用途 ≠ 场景图层。同一张图可以既是 A 角色的表情素材、又被另一个图层引用，但不会因此合并角色。

`dist/core.js` 里新增 `characterIn / expressionIn / castAlong / stage / speakerOf / characterUsage / expressionUsage`，编辑器、试玩与导出播放器共用同一套解析。

## 2. 表情如何生效

`C.stage(project, nodeId, trail)` 返回「舞台实际使用的图层」：

1. 先用 `scene()` 沿实际路径解析场景（沿用上一画面 / 独立画面），几何、图层 ID、层级、透明度、运动都来自原图层；
2. 再用 `castAlong()` 沿同一条路径结算每个角色的当前表情（本句的 `expressionId` 与 `cast` 覆盖上一层；独立画面先清空再应用）；
3. 只有素材关联被替换：返回的是浅拷贝图层（`asset` 换成表情素材），原图层对象不被改写。

因此：

- 切表情不跳位、不累计缩放、不新增图层，效果仍绑定同一个图层 ID；
- 同一句台词在 A 分支切表情，不会写到 B 分支的图层上；
- 「沿用上一画面」仍然按实际分支路径工作；
- 播放器与编辑器没有第二套解析规则，`dist/player.js` 也调用 `C.stage`。

## 3. 迁移

`migrate()` 明确按 `schema` 版本升级：V0.1 → 2 → 3 → 4。升级到 4 时只做加法——补 `characters: []`、节点的 `speakerId/expressionId/cast`、图层的 `characterId/expressionId`。不按 `name` 文本猜人物，不合并同名角色，不改任何坐标与效果参数。

桌面工程目录的 `project.paper.json` 现在写 `schema: 4` 与 `characters`；`formatVersion` 仍为 1，因此旧的 V0.3.1 工程目录（`schema: 3`）可以照常打开并就地升级。反过来，本版写出的工程不能被 V0.3.1 打开，这是有意的版本隔离。

## 4. 界面

- 左栏新增「角色」页：角色列表（姓名颜色圆点、表情数、默认表情）、新建角色、角色名称、姓名颜色（取色器 + `#RRGGBB`）、默认表情、表情缩略图列表（设为默认 / 改名 / 删除）、引用统计。
- 右栏「角色与表情」：说话角色（含「自由填写 / 旁白」）、本句表情（含「沿用画面上的表情」）、同场其他角色的表情、当前生效状态（角色名显示为该角色的姓名颜色）。绑定角色后，普通「说话人」输入框会停用，避免两套名字打架；取消角色即回到自由文本。
- 图层属性新增「图片属于角色」，把已有立绘认领给角色，供表情替换使用。
- 删除角色/表情时先统计引用（台词数、图层数、是否默认表情），再让作者选择「替换为…」或「保留占位」。保留占位不会被静默忽略：剧情检查会明确报错。
- 上传角色立绘时，如果当前台词已绑定角色，新图层会自动认领该角色。

## 5. 一致性

- 保存 / 另存为 / 自动保存 / 备份 / 恢复：`characters` 与节点、图层一起写入 `project.paper.json`，`atomicWrite` 覆盖全部字段。
- 撤销 / 重做：`snapshot()` 深拷贝 `characters`，撤销角色改名、表情增删、绑定都可用。
- 导出 HTML：工程 JSON 原样内嵌，播放器用同一个 core 解析 `characters / speakerId / cast`，姓名颜色一并导出。

```bash
node scripts/check.cjs          # 逻辑 + 存储 + 导出 + 安全 + 目录卫生（含 characters.test.cjs）
npm run desktop:smoke          # 真实窗口：编辑、存档、备份、导出
npm run desktop:smoke:project  # 真实主进程：新建 / 保存 / 重开
npm run demo:acceptance        # 《晚风经过二楼走廊》真实素材验收（见下）
```

`tests/characters.test.cjs` 覆盖：schema 4 迁移不动原有图层与演出、表情切换只换素材、路径级表情隔离（含同场双角色）、角色改名不断开绑定、表情/角色丢失的报错与替换、落盘回读、导出播放器的表情与姓名颜色。
