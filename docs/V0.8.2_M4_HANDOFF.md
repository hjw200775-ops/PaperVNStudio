### M3B 修掉的关键缺陷

`dist/player.js` 曾把 `!animate||prefersReduced()`（reduced 语义）传给参数名为 `animate`
的 `runAudioPerformance`，导致**正式播放器在正常播放时完全不执行时间轴的一次性音频**
（SFX / Voice / 交叉淡化 / Ducking），而**读档/返回时反而重放历史音效**。
编辑器时间轴预览与编辑器普通试玩走各自的驱动，不受影响，所以 M3A 的语义一致性
测试发现不了；只有真实发布载体才暴露。M3B 用最小单行修复 + 契约测试固化。
**M4 不要把这个参数方向再改回去。**

## 2. M4 要做的事（真实作品制作体验）

1. 用真实作品（不是 14 秒测试工程）从零走一遍：建工程 → 导入素材 → 写剧本 →
   排时间轴 → 试听 → 发行 → 交给别人玩。
2. 人工听感与艺术方案确认：循环点、交叉淡化曲线、Ducking 强度、镜头与角色走位。
3. 第二台机器 / 不同 GPU / 不同声卡的人工验收；安装向导与「未知发布者」提示。
4. 如有条件，补扬声器 / 声卡回环采集，把「在线音频图起音」与「实际发声」之间的
   系统延迟单独量化（M3B 明确不含这一层）。
5. 真实作品的长时播放体验（本轮 900s 浸泡判定为不需要，见音频回归报告；
   M4 若改了音频引擎或缓存策略必须重跑）。

## 3. 明确留给 M4 或后续专项的缺口

- `dist/core.js` 的 `analyze()` 与 `desktop/project-store.cjs` 的 `inspectReferences()`
  **没有校验 `node.performance.actions` 里的素材引用**：删掉只在时间轴演出里用到的
  素材不会在「检查剧情」里报错。导出链路本身（`referencedAudioIds` /
  `referencedImageIds`）已覆盖并实测通过，所以这是校验提示缺口，不是丢资源。
  改动涉及核心校验语义，需专项评估后再做，不要在 M4 顺手重构。
- 发布播放器没有自动播放 / 快进的独立 UI 按钮，按钮级行为标为 NOT_RUN；
  等价行为（连续点击推进、阻塞演出点击跳过、非阻塞跨节点、分支汇合）已由
  `v082m3b-interaction-extra.cjs` 实测通过。若 M4 要补按钮级验收，需先增加该 UI 能力。
- 跨节点时间轴、音频裁剪 / 变速、视频 / Live2D：始终不在 V0.8.2 范围。
- 单文件 HTML 默认全量内嵌图片（14 秒测试工程约 38 MB），目录版 / ZIP 才裁剪。
- 代码签名、多平台、自动更新、正式发版流程。

```bash
npm run check

# 发布运行时一致性（PVN_DEV=1 用源码 Electron；不带则用最终便携版）
PVN_PHASE=all node scripts/v082m3b-release-verify.cjs
node scripts/v082m3b-avsync.cjs

node scripts/v082m3b-audio-regression.cjs
node scripts/packaged-smoke.cjs release/PaperVNStudio-0.8.2-M3B-win-x64/PaperVNStudio.exe

node scripts/build-win-dir.cjs
```

证据文件集中在 `release/v082m3b-*.json`，截图在 `docs/screenshots/v082m3b-*.png`。
软件版本唯一来源是 `package.json` 的 `version` / `versionLabel`，
改版本时 `tests/version-consistency.test.cjs` 会强制各位置同步，并保护独立技术版本字段。
