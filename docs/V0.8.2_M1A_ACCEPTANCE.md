## 2. 实现要点（对应需求 1–5）

1. **面板渲染**：选中节点后用 `TL.toTimeline(actions)` 投影出轨道/片段/刻度/播放头；支持并行片段、
   零时长瞬时事件（`◆`）、无动作空状态。时间轴不保存第二份动作或排程数据。
2. **片段拖动**：交互期间只改该片段 DOM 的 `left`（临时预览），动作数据不变；松手用一次
   `edit()` + `TL.setStart()` 写回绝对秒，key 带递增序号以绕开 checkpoint 的 900ms 分组，
   **一次拖动 = 一个撤销步骤**。Esc / 无位移 / pointercancel / lostpointercapture / 切换节点一律取消。
3. **双向同步**：列表与时间轴按动作 ID 互相同步选择和属性；显式 `start` 存在时列表标注「绝对开始 Xs」、
   属性面板显示「绝对开始时间」并禁用 `mode/delay`（避免误以为可覆盖），提供「恢复相对时间」清除 `start`。
4. **播放头 scrub**：每次从同一节点进入前状态重新求值（`PF.emptyState()`，纯函数不累加），
   只调 `PF.applyDOM` 改画面，**不触发 SFX/Voice、不切换或重启 BGM**；切节点由 `reset()` 重建基线并清舞台 transform。
5. **松手后刷新**：`edit()` → `render()` 用真实 `schedule()` 重算整条时间轴；后续相对动作跟随，
   列表与时间轴同时反映，**绝不偷偷给其它动作写 `start`**。

## 5. 人工验收操作说明

1. 双击 `release/PaperVNStudio-0.8.1-win-x64/PaperVNStudio.exe`，打开《晚风》隔离工程。
2. 左侧选中一句带演出的剧情，舞台预览下方出现「演出时间轴」：轨道名、彩色片段、时间刻度、绿色播放头。
3. **拖片段**：按住片段左右拖动，松手才写入「绝对开始时间」；右侧动作列表、属性面板同步刷新。
   按 Esc 或原地松手可取消，不留改动。
4. **恢复相对时间**：选中带 ● 的片段，点面板底部「恢复相对时间」（或属性面板里的同名按钮）。
5. **拖播放头**：在时间轴空白处按住左右拖动，舞台画面实时变化；反复前后拖动不会响音效、不会重启音乐。
6. **保存重开**：改完点「保存工程」，关闭程序再打开，确认片段位置与绝对开始时间仍一致。
7. 撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z）应逐步回退 / 恢复每次拖动。
