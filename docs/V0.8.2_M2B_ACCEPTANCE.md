# V0.8.2 · M2-B 时间轴实时音视频同步预览 · 验收记录

> 基线 `186cc0f`（M2-A），分支 `feature/v0.8.2-timeline`；开工时 Git 干净、`main` 未动、未推送。
> 冻结模块**核心语义未改**：`dist/performance.js`（schedule/stateAt 求值）、`dist/player.js`、
> `dist/core.js` 迁移、V0.7.6 资源存储。`dist/audio.js` 仅做**最小能力扩展**：给
> `applyAudioState(state, options)` 增加可选 `options.offset`（暂停后继续时恢复 BGM 播放位置），
> precise 分支透传（`AudioBufferSourceNode.start(when, offset)` 原生支持），stream 分支设一行
> `currentTime`；不传 offset 时行为与之前逐字节一致，向后兼容。未改动核心音频引擎、未放宽任何安全机制。

## 1. 实现要点

| 需求 | 落地 |
|---|---|
| M2B-0 架构审计 | 7 个预览事件只作状态转换输入；`stateAt` 的「t ≤ slot.start 即跳过」语义与「扫描区间 ≥ 起点」严格互补，无需重写音频引擎 |
| M2B-1 统一时间基准 | 视觉沿用单调时钟 `anchorT+(now-anchorWall)/1000`；音频事件由视觉时钟的 `onTick(t)` 驱动扫描 `(lastT, t]`，不累加固定帧增量、不依赖 rAF 命中边界；BGM 精确循环仍由 AudioContext 时钟接缝；窗口卡顿时视觉追赶正确时间，不延迟音频序列 |
| M2B-2 音频事件调度 | 新增 `createPreviewAudioDriver`（`dist/timeline-preview-audio.js`，可注入可测试）：订阅 7 事件 + onTick；正常播放扫描区间内全部音频动作（状态+一次性），复用既有 `perfAudioAction`；同一时间事件按 `schedule()` 稳定排序确定执行顺序；掉帧跨越事件按「执行」规则补触发（短音效/叙事语音不无声遗漏） |
| M2B-3 任意时间开始/定位 | `applyStateAt(t)` 落地「严格 < t」的历史累积（BGM/bus/ducking 目标状态），一次性音频从 `lastT` 重新扫描——从 5s 开始时 4s 历史 SFX 不重放、6s Voice 正确触发；seek 只落状态、绝不重放历史一次性音频 |
| M2B-4 暂停/继续/停止 | 暂停即 `stopAll()`（画面冻结、音频同步停、记录 BGM 位置）；继续 `applyStateAt(curT, offset)` 恢复位置；停止 `stopAll()` 清空本预览全部播放任务、无残留声音；复用 AudioContext 不销毁重建 |
| M2B-5 区间循环 | A 时间轴循环回绕到区间起点即重建状态、区间内 SFX/Voice 每轮重新触发；B BGM 素材精确循环（V0.8.1）不混用；区间预览不写工程 |
| M2B-6 竞态与生命周期 | driver 维护 `active/lastT/boundaryInclusive/generation`；暂停/停止/seek 递增代际并 `stopAll()`，过期异步结果由 audio.js 既有 `loadSeq` 丢弃；`playbackStats()`/`dualBgm` 诊断能力复用，不隐藏错误 |
| M2B-7 编辑器交互 | 移除「视觉连续预览」占位说明，改「视觉与音频已同步预览」；`tlAudioState` 提示未解锁/`AudioContext suspended`/错误；预览复用全局音量与静音；播放中编辑沿用 M2A「停止旧计划→更新→重建」；与普通试玩双向互斥 |

**关键不变式**：`applyStateAt(t)` 落地 `< t` 的历史累积 + 扫描触发 `≥ t` 的事件，两者边界严格互补，
因此「从任意时间开始」「正常播放」「循环回绕」三者的音频语义统一且无重复、无遗漏。

### C. 尚未测试 / 明确限制

- 精确 `P95 ≤ 50ms` 音画偏差的量化测量：本轮采集的是「计划触发时间 vs 在线音频图 RMS」证据，
  未做逐事件毫秒级偏差统计；AudioContext 调度时间不等于扬声器发声时间，测量方法与适用范围在报告注明。
- 完整（非短跑）300 秒混合音视频预览与 10 次以上区间循环，需在最终 Windows 便携版上执行长跑复验。
- 1.47 GiB 全链与 900 秒音频浸泡 —— 本轮未改核心音频运行时与资源存储，按范围不重复。
- 人工长时间使用体验与第二台机器验收 —— 由用户决定。
