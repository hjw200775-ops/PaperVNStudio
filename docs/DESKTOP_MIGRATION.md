# V0.3 Desktop Preview 迁移说明

## 原则

目前导出的是网页项目源码，不是已有桌面工程。优先复用前端、数据模型与效果播放器，新增桌面窗口及文件存储适配层。不要先做 V0.4 功能，也不要为了桌面版重写播放逻辑。

桌面框架建议先评估 Electron；具体依赖版本、协议处理与打包方式由本机开发工具核对官方文档后选定。此包未安装任何桌面框架依赖。

## 建议目录（由 AI 在实施时建立，不代表已完成）

```text
project root/
  desktop/             # main / preload，窗口与受控 IPC
  adapters/            # web / desktop 存储适配
  dist/                # 当前网页编辑器，后续可渐进拆分
  tests/               # 现有与新增逻辑/存储测试
  docs/
  release/             # 忽略的打包产物
```

## 用户工程目录示例

```text
我的作品/
  project.paper.json
  assets/
    images/
      stable-id.png
  backups/
```

具体格式应版本化并写清迁移规则。原始网页 schema 1/2/3 使用内嵌 data URL；桌面相对路径工程不能直接混用同一字段而没有版本标记。建议在 IO 边界将磁盘格式解析为兼容的运行时模型，避免首轮连带改造所有渲染代码。

加载图片可以使用受控应用协议或白名单资源映射。blob URL 仅能作为当前进程的临时呈现地址，不写入永久工程，也不用于离线导出。

备份元数据只有在其引用的素材仍存在时才可恢复。首版暂不自动回收未使用素材，后续再做受控清理。

## 现有函数改造入口

| 区域 | 当前实现 | 桌面目标 |
| --- | --- | --- |
| `initialize` / `persist` | IndexedDB 单草稿 | 最近工程与目录保存；网页版保留原方式 |
| `pick` / `upload` | 浏览器选图，转 data URL | 原生对话框/受控复制；导入后使用内部素材 ID |
| `loadProject` | 校验、解码、迁移旧 JSON | 保留旧导入能力，另加目录工程读取 |
| `download` / `#save` | Blob 下载完整 JSON | 原生安全保存、另存为与备份 |
| `#export` | 嵌入数据和工厂函数输出 HTML | 保持自包含，脱离应用资源路径 |
| `snapshot` / `restore` | 内存撤销、素材数组引用 | 保持逻辑语义，避免保存与撤销彼此覆盖 |
| `core.scene` | 脚本/真实路径场景解析 | 不改变分支继承语义 |
| `effects.before/frame/animate` | 确定性效果状态 | 编辑器、导出播放器继续共用 |

## 里程碑与范围

- M0：跑通原版和测试，建立源码基线。
- M1：独立窗口，无需开发服务器的打包运行入口。
- M2：工程目录、旧 JSON 导入、新建/打开/保存/另存为/备份/恢复。
- M3：保留 HTML 导出，提供 Windows 制作器构建流程与产物，完成可行的本机验收。
- M4（后续）：独立游戏 EXE、多平台、自动更新和发布流程。

暂缓：BGM、TTS、好感度、完整时间轴、AI 单图动作生成、云同步、协作编辑。

## Git 与公开发布

源码可初始化为本地独立 Git 项目；此包未附带云端源站的 `.git` 和部署绑定。先提交基线，后续每个里程碑独立提交。远程仓库、许可证与公开素材由用户明确决定，不把“代码能运行”当作“可以公开任何素材”。
