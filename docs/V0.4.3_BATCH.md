# V0.4.3 · 批量编辑

范围：一次选中多句，批量设置角色与表情、复用场景与演出，先预览再应用，整批可撤销。不做音频、TTS、Live2D、变量条件、云服务与独立 EXE。

## 1. 多选

- 左栏工具栏「批量编辑」进入/退出；进入后每句前面出现勾选框，工具栏显示「已选 N 句 · 跨 M 段」。
- 勾选：点勾选框；点句子行会同时「查看该句 + 勾选」，Shift 点击按 **`nodes` 播放顺序** 连选到上一次点击的位置。
- 段落标题上的「全选」可取选/取消该段全部句子；折叠的段落不会清空选择，标题上显示「已选 N」。
- 当前查看的句子用绿色描边（`.active`），批量选中的句子用浅绿底 + 勾选态（`.picked`），两者可以同时存在。
- 选择集合只保存节点 ID：删除节点后自动清理，打开另一个工程时整体清空。
- 批量模式下拖动排序被禁用，避免勾选时误拖；文本框的输入与快捷键不受影响。

## 2. 批量设置角色与表情

字段独立勾选，未勾选的字段保持原样：

| 字段 | 作用 | 清空 |
| --- | --- | --- |
| 说话角色 | 设置 `speakerId` 并同步 `name` | 选「旁白 / 自由文本」= 清空角色，保留原来的名字文字 |
| 本句说话角色的表情 | 设置 `expressionId` | 「沿用画面表情」= 清空 |
| 指定在场角色的表情 | 写入/更新本句 `cast` 中该角色的一条 | 「清除该角色在本句的表情」 |

规则：

- 表情必须属于对应角色；换角色时旧表情若不属于新角色，改为**新角色的默认表情**（没有默认则清空为沿用），预览会写明。
- 在场角色表情只改本句绑定，不动图层位置/大小/顺序，也不动其他角色；不新增图层，也不会让角色出场。
- 画面里没有该角色、该角色对应多个图层、或该句在分支之后画面不唯一（`entryPlan` 判为有歧义）时，**跳过并给出原因**。
- 同一角色同时设了说话表情与在场表情属于冲突，该句不写入。
- 本轮只作用于对话/旁白节点；选项与结局节点跳过并说明，避免改动结构。

## 3. 复制 / 粘贴场景

- 「复制场景」取当前查看句自己保存的独立场景；若是「沿用上一画面」，提示先用「独立画面」建立，不推断。
- 「粘贴场景」把勾选的目标改成独立场景并替换图层：保留素材引用、位置大小、顺序、透明度、隐藏、锁定与角色/表情绑定，**保留图层 ID** 以维持演出引用。
- 不复制台词、节点 ID、跳转、选项、结局、段落归属与本句演出。
- 目标原有演出若指向粘贴后不存在的图层，或图层上的角色/表情已失效，该目标不写入并列在预览里。

## 4. 复制 / 粘贴演出

- 「复制演出」取当前句的演出；「粘贴演出」先选 **替换** 或 **追加**。
- 保留类型、起止值、时长、延迟、缓动、原点与 `sentence / hold / auto` 策略；复制后生成新的演出 ID。
- 图层匹配顺序：同 ID 且角色语义一致 → 唯一角色身份 → 否则视为不明确，**跳过该目标并说明**（不按下标猜，也不默认落到第一张图）。
- 目标在分支之后、画面无法确定时整体跳过，不复用某条路线的画面。
- 追加时若与目标已有的「同图层同类型」演出重复，按引擎现有约束判为冲突并阻止写入，提示改用替换。

## 5. 预览、应用与撤销

- 所有批量写入先由 `planBatch / planPasteScene / planPasteEffects` 生成计划，再整体应用。
- 预览显示：已选 / 可修改 / 跳过 / 冲突句数、修改字段与覆盖方式、前几句的「前后对照」（可展开全部）、跳过与冲突原因。
- 取消不改工程；应用前会**重新计算一次计划**，若预览后数据变化会提示并重新预览。
- 每次应用是一条撤销记录：撤销一次退回整批，重做一次恢复整批；没有实际变化时不产生记录、不触发保存。
- 应用时逐节点克隆 `cast` 与图层/演出对象，节点之间、与源句之间互不共享可变对象。

## 6. 顺带补强

- `entryPlan` 增加枚举预算：最多 24 条路线、4000 步、每个入口 8 条；达到上限立即停止并标记 `truncated`，此时**不会**报告「唯一」，而是让作者选择更明确的试玩入口。
- 「未分组」区域增加说明：「此处仅集中显示，实际播放位置保持原样。」排序规则不变（未分组句子仍在数组原位）。
